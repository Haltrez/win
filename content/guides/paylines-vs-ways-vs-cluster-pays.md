Every slot needs a rule for deciding which symbols count as a win. There are five main systems, and once you recognise them, any new game's paytable becomes much easier to read.

## 1. Paylines

The original system. Fixed lines run across the reels, and you win when matching symbols line up on a line from left to right. Many games have 10, 20 or 25 fixed lines. [Book of Dead](/slots/play-n-go/book-of-dead) uses 10 lines; Thunderkick's [1429 Uncharted Seas](/slots/thunderkick/1429-uncharted-seas) uses 25.

Some payline games also pay **both ways** (right to left as well), which roughly doubles how often lines connect.

## 2. Ways to win (243, 1024, 4096…)

Instead of fixed lines, matching symbols just need to appear **on adjacent reels from the left**, in any position. On a 5x3 grid that gives 243 ways; a 6x4 grid gives 4,096. Ways games produce more frequent small hits than line games of the same size.

## 3. Megaways and variable ways

Big Time Gaming's **Megaways** changes each reel's height on every spin, so the number of ways changes too – up to 117,649 on six reels. [Extra Chilli](/slots/big-time-gaming/extra-chilli) is a well-known example. Nolimit City's **xWays** and Thunderkick's random reel heights in games like [Carnival Queen 2](/slots/thunderkick/carnival-queen-2) are close cousins: the grid's shape decides how many ways are in play. See all [Megaways slots](/best/megaways-slots).

## 4. Cluster pays

Wins form when a group of matching symbols – usually five or more – **touch horizontally or vertically** anywhere on the grid. [Reactoonz](/slots/play-n-go/reactoonz) is the best-known example. Cluster games nearly always use tumbling reels so one win can lead to the next. More in [cluster pays explained](/guides/cluster-pays-explained).

## 5. Scatter pays (pay anywhere)

Symbols don't need to touch at all: land **enough of the same symbol anywhere** – often eight or more – and you win. [Sweet Bonanza](/slots/pragmatic-play/sweet-bonanza) popularised the format. Thunderkick's *Occurrence Pay* and Nolimit City's Duck Hunters series use variants of the same idea.

## Which system should you choose?

| System | Typical feel |
|---|---|
| Few paylines | Simple, easy to follow, wins tied to specific lines |
| Ways / Megaways | More frequent combinations, variable excitement |
| Cluster / scatter pays | Board-game feel, built around tumbles and multipliers |

The pay system is mostly a matter of taste. RTP, [volatility](/guides/slot-volatility-explained) and max win matter far more for your results – compare them on any slot page before you play.
